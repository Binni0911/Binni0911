# Hi, I'm Brynjólfur (Binni) 👋

Learning programming and data science in Fosnavåg, Sunnmøre.
Lærer programmering og data science på Sunnmøre.

I like taking messy data sources — APIs, spreadsheets, open public data — and turning them
into reliable pipelines, databases and simple tools people actually use.
Background from the fishing industry.

### What I'm building and learning
- **Data pipelines** that fetch and clean data automatically every night (Python, PostgreSQL)
- **Dashboards and web tools** on top of that data (Next.js, TypeScript)
- **AI features with guardrails** — checked, labelled and cost-capped (Claude API)
- **Small, reliable hosting** — Docker, backups, monitoring

### Main project
**Innsyn** — the Norwegian parliament in plain language, in Norwegian and English.
A personal learning project that pulls the Storting's open data every night: 673 bills,
2,000+ votes and 300,000+ individual MP votes, with AI summaries checked against the source.

### Tech
Python · PostgreSQL · Next.js / TypeScript · Docker · Linux · Claude API
